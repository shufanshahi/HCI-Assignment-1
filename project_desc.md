Project: ReflectBlocks

1. Core Features

A. Quick Thought Input
The user starts by writing a short sentence or phrase, such as:
“I felt nervous during today’s presentation.”

B. Optional Reflection Blocks
The system suggests a few relevant blocks, for example:
What happened?
How did you feel?
Why did it affect you?
What did you learn?
What would you do differently?

C. Block Customization
Users can:
answer a block;
leave it empty;
edit the question;
remove it;
add a custom block;
rearrange blocks.

D. Blank Writing Mode
Users who do not want prompts can write freely in a normal journal editor.

E. Journal Generation
After completing the desired blocks, the user can explicitly request the system to organize the responses into a journal entry.

F. Editable Final Entry
The generated entry remains fully editable. The user can change, remove, or add any sentence.

G. Source Transparency
Generated sections can indicate which reflection blocks they came from, helping users understand how the entry was created.

H. Save and Delete Controls
Users can:
save the complete entry;
save only the original blocks;
export the entry;
delete the entry permanently;
choose not to save anything.

I. Privacy Controls
The system clearly explains:
what information is stored;
where it is stored;
whether AI processing is used;
how the user can delete the data.
